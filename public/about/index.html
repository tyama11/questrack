Questrack:間違えた問題だけを復習できる問題追跡アプリ

Questrackは、資格試験の過去問演習や各種試験対策において、問題ごとの解答状況を素早く記録し、間違えた問題を集中的に復習して弱点克服を支援する問題追跡アプリです。

Webアプリを開く

特徴

  • 柔軟な問題数管理：科目ごとに10問、50問、100問、200問など、任意のサイズの問題集で正解・不正解・未解答を1問単位で追跡できます。
  • キーボード入力に対応：Oで正解、Xで不正解、Uで未解答に戻します。OまたはXを入力すると、自動で次の問題へフォーカスが移動します。
  • 間違えた問題の抽出とメモ：フィルター機能で間違えた問題のみを表示できます。また、各問題に間違えた理由をメモとして記録可能です。
  • 復習モード：間違えた問題を1問ずつ大きなカード形式で表示し、再度解いて正解したらその場で正解として更新できます。
  • リアルタイム進捗バーと正答率：進捗状況と正答率がリアルタイムでバー表示されます。
  • 環境に合わせた表示と多言語対応：OSの設定に連動するダークモードと、OSの言語設定に応じた日本語・英語UIの自動切り替えに対応しています。

使い方

  1. 科目や問題集の単位を作成し、演習する問題数を設定します。
  2. 問題演習を進めながら、キーボード（O / X / U）または画面操作で各問題の正誤を入力します。
  3. 間違えた問題には必要に応じて原因や解説のメモを残し、フィルターを使って不正解の設問を確認します。
  4. 復習モードを活用して間違えた問題のみを1枚ずつ解き直し、理解できた問題を正解へと更新していきます。

主な活用例

資格試験や受験の問題演習と復習に利用できます。

  • 資格試験の過去問演習：ITパスポート、基本情報技術者、簿記、TOEIC、宅地建物取引士（宅建）、ファイナンシャル・プランナー（FP）などの過去問演習と弱点補強。
  • 大学受験・高校受験の演習：大学入学共通テスト各科目の過去問演習、単語テストの定着確認。

Web版とデスクトップ版

Web版：インストール不要でブラウザから直接利用できます。データはブラウザのローカルストレージに保存されます。キャッシュ消去時やプライベートブラウジング時にはデータが消失する可能性があるため、データタブ内のJSONエクスポート機能による定期的なバックアップが可能です。

デスクトップ版：macOS（Apple Silicon / Intel）およびWindows 10/11 64bitに対応しています。完全オフラインで動作し、データは端末内にローカル保存されます。最新リリースページよりダウンロード可能です。なお、macOSでは「未確認の開発元」の警告が表示される場合があります。その際はアプリを右クリックして「開く」を選択してください。
