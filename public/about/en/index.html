Questrack: Track Wrong Answers and Review Only What You Missed

Questrack is a study tool designed to track question-by-question progress across workbooks and focus review on incorrect answers.

Open Web App

Features

  • Tracks correct, incorrect, and unanswered status per question for workbooks of any size (such as 10, 50, 100, or 200 questions), organized by subject.
  • Fast keyboard entry: press O for correct, X for incorrect, and U to return to unanswered. Focus moves to the next question automatically after pressing O or X.
  • Filter to view only incorrect questions.
  • Per-question notes to record why you got an item wrong.
  • Review mode displays incorrect questions one at a time as large cards, allowing you to mark them correct once solved.
  • Real-time progress and accuracy bars.
  • Dark mode support following the operating system appearance.
  • Japanese and English user interface following the operating system language.

How to use

  1. Create a workbook with the required number of questions and organize it by subject.
  2. Enter your answers using the keyboard: press O for correct, X for incorrect, or U for unanswered.
  3. Filter by incorrect questions and add notes explaining why each question was missed.
  4. Enter review mode to go through incorrect questions as cards, marking them correct as you solve them.

Use cases

  • Certification exam past papers (such as IT Passport, Fundamental IT Engineer, bookkeeping, TOEIC, real-estate transaction agent, and FP).
  • University and high-school entrance exam practice (such as Common Test subjects and vocabulary tests).

Web and desktop versions

Web version

Requires no installation. Data is stored in browser local storage. Data may be lost when browser cache is cleared or when using private browsing mode. You can back up your data via JSON export in the data tab.

Desktop version

Available for macOS (Apple Silicon and Intel) and Windows 10/11 64-bit. It works fully offline and stores all data locally. Download it from the GitHub releases page. On macOS, an "unverified developer" warning may appear; right-click the app and choose Open.

Source code and documentation are available on GitHub.
